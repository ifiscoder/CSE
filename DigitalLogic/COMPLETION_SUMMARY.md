## 🎯 Complete Syllabus Coverage

### **Module 01: Number Systems** (3 hours)
- Binary, Octal, Decimal, Hexadecimal conversions
- 1's complement, 2's complement representation
- BCD, Excess-3, Gray Code
- Fixed-point and floating-point (IEEE 754)
- Conversion tricks and shortcuts
- **Exam Weight**: 5-10% GATE, 8-12% ESE

### **Module 02: Boolean Algebra** (4 hours)
- All 7 logic gates (AND, OR, NOT, NAND, NOR, XOR, XNOR)
- Boolean laws, theorems, De Morgan's
- Universal gates (NAND, NOR)
- Canonical forms (SOP, POS)
- Minterms, Maxterms, Duality
- **Exam Weight**: 15-20% GATE, 12-15% ESE

### **Module 03: Minimization** (5 hours)
- K-Map (2, 3, 4, 5, 6 variable)
- Don't care conditions
- Prime implicants & Essential prime implicants
- Quine-McCluskey method
- POS minimization
- **Exam Weight**: 10-15% GATE, 10-12% ESE

### **Module 04: Combinational Circuits** (8 hours) 🆕
- **Multiplexers**: 2:1 to 16:1, tree structures, function implementation
- **Demultiplexers**: Data routing, memory addressing
- **Encoders/Decoders**: Priority encoders, BCD decoders, cascading
- **Adders/Subtractors**: Half/Full adder, Ripple carry, Carry look-ahead
- **Comparators**: 1-bit, n-bit magnitude, equality
- **Parity Circuits**: Generators, checkers, error detection
- **Code Converters**: Binary-Gray, BCD-Excess3, BCD-7segment
- Gate count formulas, implementation tricks
- **Exam Weight**: 20-25% GATE, 18-22% ESE

### **Module 05: Sequential Circuits** (10 hours) 🆕
- **Latches**: SR (NOR/NAND), D latch, gated latches, metastability
- **Flip-Flops**: D, JK, T, SR with truth/excitation tables
- **Master-Slave**: Edge-triggered design, race conditions
- **Timing**: Setup time, hold time, propagation delay
- **Conversions**: Any flip-flop to any other (with gate counts)
- **Registers**: SISO, SIPO, PISO, PIPO, shift, universal
- **Counters**: Ripple, synchronous, MOD-N, ring, Johnson, up/down
- **State Machines**: Mealy vs Moore, FSM synthesis, state reduction
- **Sequence Detectors**: Overlapping/non-overlapping patterns
- **Exam Weight**: 25-30% GATE, 25-30% ESE ⭐ HIGHEST

### **Module 06: Logic Families** (4 hours) 🆕
- **TTL**: Standard, LS, ALS, S subfamilies
  - Logic levels (0.8V/2V thresholds)
  - Fan-out (10-20 typical)
  - Propagation delay (3-10 ns)
  - Power dissipation (10-22 mW/gate)
  - Noise margin (0.4V)
  
- **CMOS**: HC, HCT, LVC subfamilies
  - Logic levels (rail-to-rail)
  - Very low static power
  - Higher speed than TTL
  - Better noise immunity
  
- **ECL**: Fastest logic family
  - Current steering logic
  - High power consumption
  - Small logic swing
  
- **Comparisons**: Speed-power product, interfacing
- **Exam Weight**: 5-8% GATE, 8-10% ESE

### **Module 07: Memory & PLD** (4 hours) 🆕
- **Memory Organization**: 1D, 2D, 3D arrays, address decoding
- **SRAM**: 6T cell, bistable, fast, expensive
- **DRAM**: 1T1C cell, refresh (2-64ms), capacitive storage
- **ROM Types**: 
  - Masked ROM (factory programmed)
  - PROM (OTP - one-time programmable)
  - EPROM (UV erasable)
  - EEPROM (electrically erasable)
  - Flash (NAND/NOR, SLC/MLC/TLC/QLC)
- **PLA vs PAL**: Programmable AND/OR arrays
- **FPGA**: LUT, CLB, routing, reconfigurable
- **Capacity Calculations**: Address lines, data lines, chip organization
- **Exam Weight**: 10-15% GATE, 10-12% ESE

### **Module 08: Master Tricks** (5 hours) 🆕
- **Gate Count Formulas**: Quick estimates for all circuits
- **Flip-Flop Conversions**: One-line transformations with gate counts
  - D→T, D→JK, D→SR, T→D, JK→D, JK→T, etc.
- **Counter Shortcuts**: MOD-N design in 30 seconds
- **MUX Universal Implementation**: Any Boolean function
- **Frequency Division**: Counter-based dividers
- **Parity Acceleration**: Tree XOR (O(log n) delay)
- **CLA Speedup**: Carry generation/propagation logic
- **Bizarre Mnemonics**: Memory aids for all major concepts
- **Pattern Recognition**: Spotting question types instantly
- **Mental Math**: Powers of 2, logarithms, hex conversions
- **Time Management**: Question prioritization strategies
- **Exam Weight**: N/A (Multiplier for all topics)
