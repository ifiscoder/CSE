# Boolean Algebra Basics

## Boolean variables and constants
- **Binary domain:** Values are only `0` and `1`.
- **Logical interpretation:** `0 = False`, `1 = True`.

## Fundamental operators
- **AND (`·`)**: Output is `1` only when both inputs are `1`.
- **OR (`+`)**: Output is `1` when at least one input is `1`.
- **NOT (complement)**: Inverts the input (`0 → 1`, `1 → 0`).

## Universal gates
- **NAND** and **NOR** are functionally complete.
- Any Boolean function can be implemented using only NAND gates or only NOR gates.
