## 🏆 Subject Strategy

* **Programming in C** is the highest-yield topic — 5-7 marks from pointer arithmetic, output-prediction, and function behavior.
* **Trees + Graphs** combined carry 5-8 marks — master traversals and BST properties.
* **Sorting** questions are almost always about **stability, time complexity comparisons, or counting swaps/comparisons**.
* **NAT questions** in this subject test precision — know exact formulas for tree node counts, hash table performance, etc.
