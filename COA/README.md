## 🔥 High-Yield Formulas (Memorize Before Exam)

### Cache Memory
```
AMAT = T_hit + (MR × T_penalty)
Offset = log₂(block_size)
Index = log₂(# lines / associativity)
Tag = Total_bits - Index - Offset
```

### Pipelining
```
CPI = 1 + stalls_per_instruction
Speedup = (n × k) / (k + n - 1) ≈ k (for large n)
RAW hazard: Forwarding or 1-cycle stall (load-use)
```

### Virtual Memory
```
PT_size = 2^VPN_bits × PTE_size
TLB_reach = TLB_entries × page_size
EAT = T_TLB + (1 - h_TLB) × T_PT + T_mem
```

### Performance
```
T = IC × CPI × T_cycle
Amdahl: Speedup = 1 / ((1-f) + f/S)
Speedup_max = 1 / (1-f) as S → ∞
```

### Number Systems
```
2's complement range: [-2^(n-1), 2^(n-1) - 1]
Overflow (signed): V = C_in ⊕ C_out (at MSB)
IEEE 754 single: S(1) | E(8) | M(23), bias = 127
```

## 💡 Pro Tips from Rank-1 Holders

### 1. The 3-Pass Rule
**Never** solve a problem only once. 
- **Pass 1:** Solve without looking at solution (day 1)
- **Pass 2:** Solve again after 3 days (test retention)
- **Pass 3:** Solve under time pressure (< 2 min, day 7)

### 2. The Error Log
Maintain a notebook:
```
Problem: [Description]
My Answer: [What I got]
Correct Answer: [What it should be]
Error Type: [Conceptual / Calculation / Careless]
Anti-Pattern: [Rule to prevent repetition]
Date: [When I'll re-test myself]
```

### 3. The Formula Derivation Test
**Every Saturday:** Pick 10 random formulas. Derive from scratch on whiteboard without notes. If any fails, that module needs revision.

### 4. The Teaching Technique
Explain each concept to an imaginary student (or real peer). If you can't explain simply, you don't understand it well enough.

### 5. The Pressure Simulation
**Weekly:** Solve 10 COA questions in 20 minutes (2 min each). Gradually reduce time. By exam week, you should solve in 1.5 min/question.
